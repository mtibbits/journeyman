# Journeyman

Journeyman is a free course in agentic development: building software by
working with an AI agent such as Claude.

It is for people who want software that lasts, not a one-shot demo. You don't
need to be a veteran programmer. You do need to be willing to be a little
careful and a little scientific.

The course is layered. Each lesson adds one habit, and each is meant to be
useful on the day you read it.

## Status

Journeyman is being written. No lessons are published yet.

## The family

Journeyman is the course for a small family of tools:

- [devagent](https://github.com/mtibbits/devagent), a Claude Code plugin that
  takes one piece of work from plan to shipped and keeps the record;
- [Gantry](https://github.com/mtibbits/gantry), planning pages for many
  projects at once.
